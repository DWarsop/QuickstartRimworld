# Quickstart for RimWorld

## Summary

A RimWorld mod that adds a "quickstart" feature, allowing players to start a new game with a pre-configured setup. This was built as a personal project to streamline my Naked Brutality playthroughs, with deaths being so common :)

The mod functions by offering settings for world and colony control. Then via a custom action, starting up a new game without the need for the player to click through the usual startup screens.

If you have any ideas for improvements or issues, feel free to open an issue on this repository.

## Features

Currently the quickstart actions is within the mod settings menu, however I'd like to move it to the main menu in the future if possible.

### Scenario Settings

- Ability to set the scenario
- Ability to set the storyteller
- Ability to set the difficulty
- Ability to set the commitment mode

### Pawn Settings

- Ability to set the ability to Self-Tend for all pawns
- Ability to set the default priorities for all pawns
- Ability to set the default assignments for all pawns
